## 🌐 Portfolio Website

I've created a modern, responsive portfolio website showcasing my journey from Data Analyst to Data Scientist to AI Engineer, with a focus on NLP and Computer Vision.

### Features:
- **Responsive Design**: Works perfectly on all devices
- **Dark/Light Mode Toggle**: Saved preference in localStorage
- **Smooth Animations**: Fade-in effects and hover interactions
- **Single Page Application Feel**: Smooth scrolling navigation
- **Modern UI**: Gradient backgrounds, glassmorphism elements, and professional layout

### Tech Stack:
- HTML5 Semantic
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript
- Lucide Icons
- Google Fonts (Inter)

### How to View:
1. Open `index.html` in your web browser
2. Or serve it with a local server for better performance:
   ```bash
   # Using Python (if available)
   python -m http.server 8000
   
   # Then open http://localhost:8000 in your browser
   ```

### Sections:
- **Hero**: Introduction with avatar and key highlights
- **About**: Personal journey and key facts
- **Projects**: Showcase of 6 featured AI/ML projects
- **Experience**: Timeline of professional roles
- **Contact**: Contact form and social links

The website is fully static and ready to deploy on any hosting platform like GitHub Pages, Netlify, or Vercel.
