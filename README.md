# Mansooho Portfolio

The personal portfolio of Mansooho (Hat Nguyen Le), an AI Automation Engineer and Technical Team Lead. It presents work across applied AI, workflow automation, backend engineering, data platforms, infrastructure and scientific research.

## Stack

- Semantic HTML5
- CSS3 with responsive layout and design tokens
- Google Fonts: DM Sans and JetBrains Mono
- No JavaScript, framework or build step

## Local development

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The site is a static GitHub Pages portfolio and is configured to work at:

`https://hatnguyenle.github.io/hathat/`

Relative asset paths are used so the avatar and favicon work from the `/hathat/` project path. No build command is required.
